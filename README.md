# EduPro Learner Analytics

A Data Science project focused on analyzing learner enrollment data to identify educational trends, explore course popularity, and generate meaningful insights through data analysis and visualization.

## Project Overview

EduPro Learner Analytics demonstrates how data science techniques can be used to explore educational enrollment data and understand learner patterns. The project uses Python-based data analysis and an interactive dashboard to make findings easier to interpret.

## Objectives

* Analyze learner enrollment data.
* Explore course enrollment patterns and trends.
* Identify useful insights from educational data.
* Present key findings using charts and visualizations.
* Build an interactive dashboard for exploring the dataset.

## Technology Stack

* **Programming Language:** Python
* **Data Analysis:** Pandas
* **Data Visualization:** Plotly / Streamlit charts, depending on implementation
* **Dashboard:** Streamlit
* **Dataset Format:** CSV
* **Version Control:** Git and GitHub

## How to Run the Project Locally

1. Install Python 3.10 or a compatible version.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Install the required libraries:

   `pip install -r requirements.txt`

5. Start the dashboard:

   `streamlit run app.py`

6. Open the local URL displayed in the terminal.

## Dataset Disclaimer

This project uses synthetic demonstration data. The dataset does not represent verified records from a real educational institution. Any patterns or insights are illustrative and should not be treated as findings about actual students or institutions.
