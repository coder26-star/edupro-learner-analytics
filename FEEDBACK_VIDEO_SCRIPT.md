# Project Feedback Video Script (about 60–90 seconds)

Hello, my name is [your name], and my project is “Learner Demographics and Course Enrollment Behavior Analysis on EduPro.”

The purpose is to summarize learner profiles, understand course demand, track monthly enrollments, and compare engagement, completion and satisfaction metrics. The dashboard is built with Python, pandas, Plotly and Streamlit.

The project includes a synthetic dataset of 1,200 learner records. The dashboard shows enrollment counts by course, age distribution, monthly enrollment trends, completion rates by course, education levels and enrollment sources. Filters allow the viewer to focus on selected courses and regions.

The data is fictional and is only used to demonstrate the analytical workflow. It must not be interpreted as actual EduPro performance. In a real learning platform, I would validate data quality, protect learner privacy, collect feedback responsibly and test whether recommended interventions improve outcomes.

This project helped me practice data cleaning, descriptive analysis, grouping, visualization, dashboard development and communicating limitations. Thank you.
